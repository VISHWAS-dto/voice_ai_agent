PHASE 2 - Audio ingestion (DONE)
================================

In one line:
Wrote the code that takes any audio clip and turns it into a clean,
standard format the model can read, plus a check for how much of the
clip is actual speech.

A bit more detail (app/audio/ingest.py):
- normalize_audio(bytes): feeds the raw audio (mp3, wav, m4a, or phone
  formats like 8kHz mu-law) through ffmpeg and gets back a 16kHz mono
  waveform. Everything happens in memory via pipes - nothing is ever
  saved to disk (the audio can contain private customer info).
  Throws a clear AudioDecodeError if the input is empty or corrupt.
- run_vad(waveform): uses webrtcvad to measure speech vs silence and
  returns total length, speech length, speech ratio (0-1), and how many
  separate speech chunks there are. Short or silent clips return a
  ratio of 0.0 instead of crashing.
  (webrtcvad picked over silero-vad: no model download, no torch, fast
  and predictable - it's just a rough "is there enough speech?" gate.)
- Pure, testable functions only - no API/route code, no global state.

Also added scripts/test_ingest.py: a manual test that runs a sample WAV
through both functions and prints the stats, and checks that silent /
empty / corrupt buffers are handled gracefully.

Note: needs the `ffmpeg` binary installed (brew install ffmpeg), and
`setuptools<81` in the venv (webrtcvad still imports the old
pkg_resources).

In Short 

1. Take the audio (mp3, wav, m4a, phone formats) → convert to the one standard format the model reads.
2. Check how much of it is actual speech (not silence/noise)
